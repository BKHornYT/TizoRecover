    Disk tools

    Tools that change a drive. Recovery never uses them.

    Erase a removable drive

    Wipes a USB stick or memory card so its files cannot be recovered, then formats it. Only removable drives are offered; your Windows drive and the drive TizoRecover runs from never are.

    Recover files

    Always save to a different drive than the one you are recovering from. Writing to it can overwrite the very files you want back, so TizoRecover refuses to.

    Erase drive

    Everything on this drive will be destroyed for good. All files, all partitions, and anything TizoRecover could have recovered. There is no undo, and no tool, TizoRecover included, can bring it back.

    USB sticks, memory cards and SSDs keep a few spare blocks that only their own chip can reach. An overwrite gets everything a computer can see, which stops every recovery tool, but not a forensic lab with the chip on a bench.
